### What I do

I build **autonomous AI agent systems** — not chatbots. Agents that perceive context, plan
across multiple steps, call real tools, manage their own memory, and finish work without
a human in the loop. The output is time saved, decisions executed, and workflows that
used to take hours now take minutes.

```
 Input   : a business workflow or a recurring task
 Process : multi-agent orchestration, tool calling, memory, self-improvement
 Output  : the task done, end-to-end, repeatable
```

**Models and SDKs.** Anthropic Claude (Opus / Sonnet / Haiku), Groq Llama 3.3, OpenAI,
Kimi (Moonshot), local Ollama, faster-whisper for STT.

**Agent layer.** Multi-agent orchestration, structured tool calling, browser-use,
Playwright, openwakeword, ChromaDB + MiniLM embeddings for semantic memory.

**Application layer.** FastAPI, WebSocket, React + Vite, Electron, Telegram Bot API,
Spotify Web API.

**Infra.** PostgreSQL, SQLite, Docker, GitHub Actions, NSIS installers.
